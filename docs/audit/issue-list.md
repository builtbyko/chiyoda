## 誤りと断定しなかったもの

- 地区計画や特例の`i`は、古い出力では当初決定日でありIDではない。重複日付を重複地物として削除しない。
- 同名・同座標・入れ子は削除根拠ではない。複数指定、別区の行、公式代表点、分離した区域が含まれる。
- 厳密な6区union境界外の微小部分は6桁丸め・簡略化の確認対象。全25GeoJSONで無効／空形状0、範囲外ポイント0。面を一括再クリップしない。
- 再開発は選択した資料からの収録で、全事業の網羅一覧ではない。文京・台東の現在収録0件は「事業なし」を意味しない。
