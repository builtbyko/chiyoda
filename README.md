# CHiYODA ATLAS

都市・地理・まちづくりを横断して千代田区を理解するための、自分用の都市アトラスです。千代田区と、境界を接する中央区・港区・新宿区・文京区・台東区を同じ条件で見比べられます。

公開URL：<https://builtbyko.github.io/chiyoda/>

## できること

- 6区・658町丁目の住民人口密度と2020年昼間人口密度を比較
- 2021年度の実土地利用を町丁目ごとの主用途に集約して俯瞰
- 用途地域を6分類の色で俯瞰し、クリックで正式名称・容積率・建ぺい率を確認
- 地区計画、高度地区、再開発等促進区・高度利用地区・特定街区・都市再生特別地区を表示
- 東京都の公式一覧で「事業中」の市街地再開発事業35件を代表点で確認
- 千代田区都市計画マスタープランの7地域を、地域名付きの薄い色面で確認
- 街の個性16界隈、公開空地173区域、まちづくり団体12区域、まちの記憶23地点を公式GISで確認
- 国・都・区文化財と景観資源111地点を統合。既存景観物件64件の指定日・個別公式資料も保持
- 地形・陰影と2020年度PLATEAU建物高さを、必要なときだけタイルで表示
- 防火地域・準防火地域と、洪水浸水想定区域（想定最大規模）を確認
- 主要道路を「首都高速／国道／都道・幹線／地区幹線」に整理
- 6区の都市計画道路（PLATEAU 2020年度）を、一般道の計画線・高速道路等・広場の3色で表示
- JR・東京メトロ・都営地下鉄など32路線と141駅を表示
- 735件の公園等、383地点の地価公示、374施設の指定避難所を必要なときだけ表示
- 町丁目・駅・公園・地区計画・特例地区・再開発・7地域・文化・歴史資源を横断検索
- 地図上の色や点をクリックして、名称・区分・価格・所管等の要点を確認
- 「現在地」で端末の位置と測位精度の範囲を表示
- 最新から1936〜1942年頃まで、8区分の航空写真を切替

背景は国土地理院の最新航空写真が初期表示です。写真を少し減彩し、主題レイヤーを用途別の高コントラスト色にしています。千代田区は黄線、6区の区界は白線で常時表示します。

## 操作

1. 左側のカテゴリから、面で見る情報を一つ選びます。
2. 都市構造、計画・変化、暮らし・景観のレイヤーを必要な分だけ重ねます。
3. 右上の情報ボタンを押すと、千代田区の統計、各レイヤーの見方・データ時点・出典を確認できます。パネルは初期状態では閉じています。
4. 地図上の面・線・点をクリックすると詳細が表示されます。凡例は左下で開閉できます。
5. 航空写真の年代を切り替えて、市街地の変化を比較できます。
6. 「現在地」を押して位置情報を許可すると、現在地とおおよその精度範囲が青色で表示されます。

## ローカルで動かす

Node.js 22.13.0以上が必要です。

```bash
npm install
npm run dev
```

航空写真タイルの表示にはインターネット接続が必要です。

```bash
npm run lint
npm test
```

## データの再生成

`scripts/build_map_data.py` は、町丁目境界、人口・昼間人口、実土地利用、都市計画、再開発、洪水、公園、地価、避難所、鉄道、OpenStreetMapの東京抽出データから、初期表示と軽量な検索索引を収めた `public/data/map-data.json` と、選択・表示時だけ読む `public/data/layers/` 以下のレイヤーファイルを作ります。詳細な地物形状を初期データへ重複収録しないため、レイヤー数が増えても最初の地図表示を妨げにくい構成です。Python環境には Shapely、GeoPandas、Pyogrio、PyProj、Requests が必要です。追加レイヤーの公式ファイルは、既存の基礎データキャッシュへ次のスクリプトで取得・展開できます。

```bash
python scripts/fetch_map_sources.py --source-root ../work/chiyoda_map/data
python scripts/build_map_data.py --source-root ../work/chiyoda_map/data
python scripts/normalize_geojson.py
```

今回の公式GISレイヤーは添付前処理スクリプトを利用し、基礎データとは別に再生成します。原ZIPは `../work/chiyoda_map/data/chiyoda/official-layers` に保存し、軽量GeoJSONと属性スキーマだけをリポジトリへ生成します。生成時に旧景観検索索引を統合済み文化・歴史資源の単一索引へ置き換えます。基礎データ再生成後にも既存の統合済み索引を復元します。

```bash
python -m pip install -r scripts/requirements-atlas-data.txt
python scripts/prepare_chiyoda_official_layers.py
python scripts/fetch_next_stage_sources.py
python scripts/resolve_plateau_metadata.py
python scripts/discover_chiyoda_arcgis.py
python scripts/prepare_river_guideline.py
```

次段階のPDF、河川SHP、ArcGIS属性カタログ、PLATEAUメタデータは `../work/chiyoda_map/data/next-stage` に保存します。PLATEAU原データ・タイルは保存しません。指定の道路網PDF URLは取得時に404でした。道路RESTには道路種別と文字列の幅員属性がありますが、再利用条件・幅員の値・単位は未確認、明示的な管理者属性もないため新しい道路レイヤーは公開しません。道路台帳PDFのデジタイズも行いません。

河川SHPは河川名属性がなく、安全に3河川へ対応付けできませんでした。`scripts/data/river-source-schema.json` の検査報告だけを生成し、「川沿いまちづくり」は追加していません。12の景観界隈も境界未取得のメタデータであり、16の街の個性とは別物です。推測境界や200m範囲は作成していません。

7地域は `scripts/data/chiyoda-regions.json` の公式町丁目対応表を、ビルド時に町丁目境界へ結合します。景観まちづくり重要物件の一覧を更新するときは、千代田区の現行一覧HTMLと、公式GISのポイントをWGS84へ変換したGeoJSONを用意し、次の順でスナップショットと地図データを再生成します。

```bash
node scripts/build_reference_snapshot.mjs path/to/ichiranhyo.html path/to/official-points-wgs84.geojson scripts/data/landscape-important-properties.json
python scripts/build_map_data.py --source-root ../work/chiyoda_map/data
```

## 注意事項

この地図は、異なる時点・定義の公開データを組み合わせた学習・概況把握用の資料です。行政上・法令上の正式な判断には使用できません。

- 人口密度は2026年1月1日の住民基本台帳人口を2020年国勢調査の町丁目面積で割った概算値です。
- 昼間人口は2020年国勢調査を基準に経済センサス・学校基本調査等から推計された値です。2026年住民人口との増減比較には使えません。
- 実土地利用は東京都の2021年度調査を町丁目単位に面積集計したものです。公開版には元の筆・画地ポリゴンを含めず、主用途と構成上位だけを収録しています。色の主用途判定では道路・鉄道・水面を除外しています。
- 用途地域を個別敷地について確認する場合は、各区・東京都の都市計画図等の公式資料を参照してください。
- 地区計画・高度地区・各種特例地区は区域を探すための索引です。高度地区は千代田区・中央区には指定がなく、地図には隣接4区の指定だけが表示されます。区域の重なりから実効容積率・実効高さを算定していません。個別敷地は公式の計画書・計画図で確認してください。
- 市街地再開発事業の点は関係町丁目内の代表位置であり、施行区域を示すものではありません。東京都の進捗区分が「事業中」のものだけを収録しています。
- 7地域は、千代田区の公式な町丁目対応表に従って2020年国勢調査の町丁目境界を結合し、マスタープラン最終版の地域区分図・地域別記載と照合した学習用ポリゴンです。個別敷地の行政上の区域確認には原典を使用してください。
- 景観まちづくり重要物件の名称・種別・所在地・指定日・個別資料は千代田区の現行一覧によります。旧56地点は千代田区公式GISの座標、追加指定8件（指定25・60〜66）は公式所在地を国土地理院住所検索で位置化した街区等の代表点です。
- 文化・歴史資源は国・都・区文化財と景観物件・景観重要建造物を一つのレイヤーへ統合しています。景観物件を別レイヤーで二重表示しません。同じ物件の複数景観指定も一地点にまとめ、異なる文化財指定は保持します。
- 公開空地・団体区域は公式GISの掲載範囲です。欠落している施設名、所在地、年度等は補完していません。団体区域は法定計画区域と同じ意味ではありません。
- 建物高さは2020年度PLATEAUの `measuredHeight` を2Dで可視化したものです。最新建物情報・高さ規制ではありません。広域ズームでは小規模建物が省略され、タイルの提供は第三者のindigo-labです。高さ不明を0mとは表示しません。
- 防火指定は概況把握用です。敷地の法令上の指定は各区・東京都の都市計画図等で確認してください。
- 洪水は複数の河川別「想定最大規模」を重ね、各地点で最も深い区分を表示しています。避難判断には各区の最新ハザードマップと発表情報を使用してください。
- 公園・緑地は概略位置を示す参考データで、境界・網羅性・現況を保証するものではありません。属性面積と表示ポリゴンの面積が異なる場合があります。
- 地価公示は標準地の1㎡当たり価格を示す点データで、個別の土地・建物の価格を示すものではありません。
- 指定避難所は取得時点の国土地理院データです。未掲載または最新でない場合があるため、実際の避難時は各区の案内を確認してください。
- 道路区分はOpenStreetMapの道路分類を学習用に整理したもので、法令上の道路種別・管理区分とは一致しない場合があります。
- 都市計画道路は2020年度の公開計画線を保持した概況表示で、現況道路や未整備区間だけを示すものではありません。元データには路線名・計画幅員・整備状況・決定年月日がないため補完していません。「立体（構想）」だけを除外し、一般道・高速道路・立体（計画）・交通広場・駅付近広場の分類を維持しています。最新の計画区域や敷地との関係は各区・東京都の公式図書で確認してください。
- 駅は国土数値情報の駅範囲から置いた代表位置で、出入口位置を示すものではありません。
- 航空写真の年代名は撮影年の幅で、区域全体が同一年撮影とは限りません。古い写真には未整備・範囲外の空白があります。
- 現在地はブラウザの測位結果で、建物内などでは大きくずれる場合があります。位置情報は保存しません。
