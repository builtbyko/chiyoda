# 千代田区ベースアトラス

千代田区の人口、用途地域、主要道路、鉄道・駅を同じ地図上で見比べるための、個人学習・地域理解用Webマップです。町丁目単位の人口密度から、皇居周辺、番町・麴町、神田、丸の内・大手町などの都市構造を俯瞰できます。

公開URL：<https://builtbyko.github.io/chiyoda/>

## できること

- 115町丁目の人口密度を段階色で表示
- 用途地域と容積率・建ぺい率を確認
- 主要道路を「首都高速／国道／都道・幹線／地区幹線」に整理
- JR・東京メトロ・都営地下鉄など18路線と29駅を表示
- 淡色地図・標準地図・空中写真を切り替え
- 「人口／都市計画／交通」のプリセット表示
- 町丁目・駅の検索、地物クリックによる詳細表示
- 道路、鉄道・駅、町丁目境界の個別切り替え

## 操作

1. 「見方のプリセット」または「面の情報」でテーマを選びます。
2. 道路、鉄道・駅、町丁目境界を必要に応じて重ねます。
3. 地図上の町丁目、用途地域、道路、路線、駅をクリックすると詳細が表示されます。
4. ドラッグで移動、ホイール／ピンチで拡大・縮小できます。

## ローカルで動かす

Node.js 22.13.0以上が必要です。

```bash
npm install
npm run dev
```

背景地図タイルの表示にはインターネット接続が必要です。

```bash
npm run lint
npm test
```

## 技術構成

- React / TypeScript
- Vinext / Vite
- MapLibre GL JS
- GeoJSON
- 国土地理院タイル

## 注意事項

この地図は、異なる時点・定義の公開データを組み合わせた学習・概況把握用の資料です。行政上・法令上の正式な判断には使用できません。

- 人口密度は、2026年8月1日の住民基本台帳人口を2020年国勢調査の町丁目面積で割った概算値です。
- 用途地域を個別敷地について確認する場合は、千代田区の都市計画図・都市計画情報提供サービス等の公式資料を参照してください。
- 道路区分はOpenStreetMapの道路分類を学習用に整理したもので、法令上の道路種別・管理区分とは一致しない場合があります。
- 駅の点は駅範囲から置いた代表位置で、出入口位置を示すものではありません。
