# 千代田区＋隣接区ベースアトラス

千代田区と、境界を接する中央区・港区・新宿区・文京区・台東区を同じ条件で見比べるための個人学習用Webマップです。

公開URL：<https://builtbyko.github.io/chiyoda/>

## できること

- 6区・658町丁目の人口密度を比較
- 用途地域を6分類の色で俯瞰し、クリックで正式名称・容積率・建ぺい率を確認
- 主要道路を「首都高速／国道／都道・幹線／地区幹線」に整理
- JR・東京メトロ・都営地下鉄など32路線と141駅を表示
- 町丁目・駅を検索し、区名を含む詳細情報を確認
- 町丁目境界、道路、鉄道・駅を必要なときだけ重ねて表示

背景は国土地理院の航空写真に固定し、写真を少し減彩して主題レイヤーの色が判別しやすい表示にしています。千代田区は黄線、6区の区界は白線で常時表示します。

## 操作

1. 「面の情報」で人口密度・用途地域・表示なしを選びます。
2. 道路、鉄道・駅、町丁目境界を必要に応じて重ねます。
3. 地図上の町丁目、用途地域、道路、路線、駅をクリックすると詳細が表示されます。
4. 「6区全体へ戻る」で対象地域全体を表示します。

## データ時点・出典

| レイヤー | データ時点 | 出典 |
|---|---:|---|
| 人口 | 2026-01-01 | [東京都「住民基本台帳による東京都の世帯と人口」第5表](https://www.toukei.metro.tokyo.lg.jp/juukiy/2026/jy26q10501.htm) |
| 町丁目境界・面積 | 2020年国勢調査 | [国勢調査町丁・字等別境界データセット](https://geoshape.ex.nii.ac.jp/ka/resource/) |
| 用途地域 | 2025年度（東京都は2026-07-01修正版） | [国土交通省「都市計画決定GISデータ」](https://www.mlit.go.jp/toshi/tosiko/toshi_tosiko_tk_000087.html) |
| 鉄道・駅 | 2025-12-31 | [国土数値情報「鉄道データ」](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N02-2025.html) |
| 主要道路 | 2026-08-30取得 | [OpenStreetMap](https://www.openstreetmap.org/)／[BBBike 東京抽出データ](https://download.bbbike.org/osm/bbbike/Tokyo/) |
| 航空写真 | 閲覧時取得 | [国土地理院「地理院タイル一覧」](https://maps.gsi.go.jp/development/ichiran.html) |

町丁目境界データは『国勢調査町丁・字等別境界データセット』（CODH作成）を使用しています。道路データは © OpenStreetMap contributors。各データの利用条件は提供元の案内に従ってください。

## ローカルで動かす

Node.js 22.13.0以上が必要です。

```bash
npm install
npm run dev
```

航空写真タイルの表示にはインターネット接続が必要です。

```bash
npm run lint
npm test
```

## データの再生成

`scripts/build_map_data.py` は、町丁目境界、東京都の用途地域、国土数値情報の鉄道、OpenStreetMapの東京抽出データから `public/data/map-data.json` を作ります。Python環境には Shapely、GeoPandas、Pyogrio、PyProj が必要です。

```bash
python scripts/build_map_data.py --source-root ../work/chiyoda_map/data
```

## 注意事項

この地図は、異なる時点・定義の公開データを組み合わせた学習・概況把握用の資料です。行政上・法令上の正式な判断には使用できません。

- 人口密度は2026年1月1日の住民基本台帳人口を2020年国勢調査の町丁目面積で割った概算値です。
- 用途地域を個別敷地について確認する場合は、各区・東京都の都市計画図等の公式資料を参照してください。
- 道路区分はOpenStreetMapの道路分類を学習用に整理したもので、法令上の道路種別・管理区分とは一致しない場合があります。
- 駅は国土数値情報の駅範囲から置いた代表位置で、出入口位置を示すものではありません。
- 航空写真は場所によって撮影時期が異なります。
